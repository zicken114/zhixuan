# 「知玄」- 知乎全场景悬浮创作舱

> 一只名叫**刘看山**的北极小狐狸住在你的桌面右侧。它会盯你正在写的稿子、剪贴板里刚复制的段落、屏幕上选中的图表，随手帮你整一段知乎高赞体。

桌面悬浮工具，专为知乎创作者打造：多窗口悬浮、AI 流式对话、视觉素材提取、灵感库语义检索、知乎热榜破题灵感、深度报告生成。

技术栈：**Tauri v2 + Vue 3 + Rust + SQLite**，本地运行，全程通过你自己的 AI Provider Key 调用云端模型。

## 快速开始

| 依赖 | 版本 |
|------|------|
| Node.js | >= 18.18.0 |
| Rust | 最新稳定版 |
| Windows | 10 / 11 |

```bash
npm install
npm run tauri dev    # 开发模式
npm run tauri build  # 生产构建
```

首次启动 → 双击悬浮球打开主窗口 → 右上角 ⚙️ → 配置 Text Model 和 Vision Model 的 Provider Key。支持 OpenAI / DeepSeek / Kimi / 智谱 / 阶跃 / MiniMax / 百炼 / Custom。

## 悬浮球（Widget）

屏幕右侧的小球，默认显示。

- **双击** → 打开主窗口
- **单击** → 弹出快捷菜单
- 拖到屏幕左 / 右边缘自动 dock，dock 后变成细条贴边
- 检测到活动应用类型（PDF / 写作 / 浏览器 / 代码编辑器）会在球上显示对应图标
- 知乎热榜抓到新内容时显示红点 + 角标，点击进入热榜面板
- 检测到上次未读完的 PDF 时显示「继续阅读」横幅

## 主窗口（刘看山聊天）

双击悬浮球打开。顶部是工具栏，左侧是聊天区，右侧根据点击的工具按钮切换不同侧边栏。

### 聊天

- 流式回复，自带知乎人设：刘看山小狐狸（谢邀 / 利益相关 / 抖个机灵 / 这是个好问题…）
- 支持项目切换：每个项目独立的对话历史、素材库、统计
- 项目可绑定关键词、关联文件夹、引用格式偏好

### 工具栏按钮（从左到右）

| 图标 | 名称 | 作用 |
|------|------|------|
| ➕ | 新建对话 | 开启新一轮对话 |
| 🕒 | 历史记录 | 切换历史会话 |
| 📖 | 知乎素材库 | 本地 PDF / 文档语义索引与检索 |
| 📝 | 写作历史 | 回看历次写作产出 |
| 🔔 | 热榜灵感雷达 | 看下面单独章节 |
| ⚡ | 创作快照 | 浏览碎片记录历史 |
| 📊 | 仪表盘 | 创作活跃度热力图 + 模型用量统计 |
| ⚙️ | 设置 | Provider Key / 主题切换 |
| ✕ | 关闭 | 隐藏主窗口 |

### 项目切换条

主窗口顶部显示当前项目，点击下拉切换；可创建 / 编辑 / 删除项目。每个项目可单独配置：名称、配色、关键词、关联素材文件夹、引用格式。

## 剪贴板快捷菜单（Popup）

`Alt + Q` 触发。后端读取剪贴板和当前活动窗口类型，根据场景渲染不同菜单：

**通用**：
- 💬 **Chat** — 把内容塞进主窗口聊天
- 🕵️ **"杠精"视角审视** — 用反向视角找漏洞、反驳点
- 📖 **盐选脑洞扩写** — 把短句扩成知乎盐选风格段落
- 📜 **History** — 历史记录

**写作应用场景额外**：
- 🌟 **转为"知乎高赞体"** — 润色为高赞体表达

**PDF 阅读器场景额外**：
- 📚 **引用润色** — 把段落整理成可引用形式
- 📝 **阅读笔记** — 基于段落生成阅读笔记

Markdown 结果会以 **CF_HTML** 写入剪贴板，可直接带格式粘贴到 Word。

## 截图提取（Capture → Result）

`Alt + S` 触发，进入全屏选区模式。拖拽框选一块区域，松开后选区下方会弹出 4 个提取按钮（自动避开屏幕边缘，不会跑出可视区）：

| 图标 | 名称 | 适用场景 |
|------|------|----------|
| 📈 | **硬核图表分析** | 截图里有数据图表，让 AI 用知乎专业但不装的口吻直接给结论 |
| 🧩 | **复杂布局拆解** | 信息密集的页面，让 AI 帮你拆视觉层级、出创作大纲 |
| ✨ | **灵感手稿一键转正** | 手写 / 潦草笔记，让 AI 整理成知乎风开场白 |
| 🦊 | **梗图解码** | 截梗图，让刘看山亲自吐槽 + 颜文字结尾 |

选定后 capture 窗口隐藏，弹出**结果窗口**：
- 处理中：进度条 + 流式预览，可一键终止
- 完成：流式结果展示，自动复制到剪贴板，可直接粘贴

阅读伴侣的 `Ctrl+Shift+2/3` 会自动预选「硬核图表分析」/「复杂布局拆解」，按 Enter 直接执行。

## 热榜灵感雷达（Sentinel）

主窗口工具栏的 🔔 按钮，或悬浮球角标变红时点进。

- 顶部「🔄 刷新热榜」按钮 + 实时/兜底数据状态标签 + 最后抓取时间
- 列出当前知乎热榜 Top 10，前 3 名带橙红渐变 rank 徽章 + 🔥 热度值
- 点击任意一条 → AI 自动拆解 3 个不同的破题角度（反常识 / 情感共鸣 / 硬核科普），并附每个角度的大纲走向
- 结果可复制大纲 / 打开原话题

> 接口不通或被 CORS 拦截时会自动切换到本地兜底数据，界面不会白屏；点击仍可正常生成破题灵感。

## 创作快照（Snapshot）

`Alt + E` 触发，弹出「📸 创作快照与碎片记录」窗口。三个字段：

1. **灵感标题** — 给一闪而过的念头起个名字
2. **一闪而过的念头** — 趁脑袋里这股劲儿打下来，一段话也行
3. **相关截图展示** — 点「📷 截取屏幕」自动截当前画面（截屏时窗口会先隐藏避免拍到自己），可重截 / 清除

保存后存入碎片库，可在主窗口的 ⚡ 创作快照面板回看，截图以缩略图形式展示。

## 知乎深度报告生成器（Review Wizard）

把多份素材合成一篇结构化长文，4 步向导：

1. **选择素材来源** — 知乎素材库 / 粘贴 DOI
2. **选择素材** — 复选框列表挑出本次要用的素材
3. **选择风格** — 深度长文 / 热点速评 / 简明概述，可填聚焦方向
4. **生成** — AI Map-Reduce：每篇素材提取核心事实 → 汇总成 5 个章节

输出结构按知乎经典「破题 → 分层解析 → 升华总结」组织：

1. 破题：话题背景与切入点
2. 分层解析：核心观点对比
3. 关键事实速查表（Markdown 表格）
4. 盲点与延伸思考
5. 升华总结

生成完成后可一键复制全文。

## 历史记录（History）

`Alt + Q` 菜单里的 📜 History 入口，或 Popup 里 History 按钮。

- 所有快捷菜单操作 + 截图提取自动入库（最多保留 50 条）
- 每条显示：原始图标 + 真实操作名（截图 4 类各自显示对应图标和标签，不再统一为"提取文本"）
- 输入栏：截图缩略图或文字内容
- 输出栏：AI 处理结果
- 一键复制输入 / 输出 / 图片
- 单条删除 / 一键清空

## 知乎素材库（Knowledge）

主窗口工具栏的 📖。

- 添加文件夹 → 自动索引 PDF / 文本文档 → 本地 embedding 模型向量化
- 在聊天时自动检索相关片段注入上下文（如开启 Auto-Retrieve）
- 列表显示索引状态（pending / indexing / completed / error）
- 可针对当前项目筛选

## 仪表盘（Dashboard）

主窗口工具栏的 📊。

- 顶部汇总卡：阅读素材数 / 对话次数 / 待办 / 创作快照数

## 设置（Settings）

主窗口右上角 ⚙️。

- **外观** — 主题模式（明 / 暗）切换
- **文本模型** — Provider 预设 / Base URL / API Key / 模型 ID
- **视觉模型** — 同上，用于截图提取
- **快捷键** — 当前注册的全局热键一览（只读）

## 常见问题

**Q：截图后再次截图鼠标按下没反应？**
已修复。第二次截图时，capture 窗口在显示前会先重置状态再载入新背景。

**Q：截图选项菜单跑出屏幕？**
已修复。`ExtractPromptMenu` 挂载后自测尺寸，右侧 / 底部越界会自动钳到屏内或翻转到选区上方。

**Q：知乎热榜接口返回 401 / 403，看到"兜底数据"标签？**
是预期行为。该接口需要登录态或签名，未携带时会失败，前端自动切到本地兜底数据，AI 联动仍可用。

**Q：富文本粘贴到 Word 失败？**
CF_HTML 仅 Windows 支持；其他平台 fallback 纯文本。

**Q：`Alt+S` 不生效？**
被其他软件占用了快捷键。

**Q：Embedding 模型下载失败？**
确认能访问 HuggingFace；不行就在素材库相关功能下使用兜底镜像 `hf-mirror.com`。
