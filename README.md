# 知玄 —— 一只住在你桌面右侧的北极狐

> 写知乎回答卡壳时，剪贴板里刚复制的段落想换个说法，或者截图里的数据图需要快速解读——不用切浏览器、不用开新标签，按一下快捷键，一只叫刘看山的北极小狐狸就会探头出来帮你。

知玄是一款桌面悬浮创作工具，专为在电脑上写知乎内容的场景设计。它不像传统AI工具那样占满一个浏览器标签页，而是以一个悬浮球常驻屏幕边缘，在你需要时一键唤出，用完即走。

技术栈：Tauri + Vue 3 + Rust + SQLite，数据存在本地，模型调用走你自己的 API Key。

---

## 它解决什么

写知乎内容时，创作者反复在几个动作之间切换：查资料、润色文字、截图做分析、找选题灵感。每个动作都要打开不同的网页或工具，上下文不断被打断。

知玄的思路是把这些高频动作收进一个始终在手边的悬浮层里，让 AI 介入的时机从"打开网页→登录→输入提示词"变成"选中内容→按快捷键→直接出结果"。

## 核心使用场景

### 场景一：写回答时卡壳，顺手润色

正在 Word 或编辑器里写回答，某段话总觉得不够味。

1. 选中文字，复制
2. 按 `Alt + Q`
3. 菜单里点「转为知乎高赞体」
4. 结果自动进剪贴板，直接粘贴覆盖原文

同样的流程也适用于：
- 把一个粗糙的脑洞扩写成盐选风格的段落
- 用"杠精视角"审视自己的论述，提前堵上漏洞
- 把参考文献整理成规范引用格式

### 场景二：看到一张数据图，想引用到回答里

网页或 PDF 里有一张图表，想快速理解数据走势并写进回答。

1. 按 `Alt + S`
2. 框选图表区域
3. 选「硬核图表分析」
4. AI 用知乎风格的口吻给出数据解读，自动复制

其他提取模式：
- **复杂布局拆解** —— 信息密集的页面，AI 帮你拆视觉层级、出创作大纲
- **灵感手稿一键转正** —— 手写或潦草的笔记，整理成知乎风开场白
- **梗图解码** —— 截梗图，让刘看山用调皮语气吐槽（这个纯属娱乐，但写得慢的时候确实能放松一下）

### 场景三：刷知乎热榜，看到感兴趣的话题想动笔

热榜灵感雷达会定时抓取知乎热榜。看到感兴趣的话题：

1. 点击热榜条目
2. AI 自动拆解 3 个不同的破题角度：反常识切入、情感共鸣、硬核科普
3. 每个角度附带大纲走向
4. 选一个顺手的，复制大纲开始写

接口异常时会自动 fallback 到本地兜底数据，不会白屏。

### 场景四：灵感突然来了，先记下来

`Alt + E` 弹出创作快照，三栏：标题、念头、截图。写完直接保存，之后在主窗口的「创作快照」面板里集中回看。截图会以缩略图形式保留，方便你记起当时看到了什么触发的灵感。

### 场景五：攒了一批素材，想合成一篇长回答

知乎深度报告生成器，四步向导：
1. 从素材库或 DOI 里选素材
2. 勾选本次要用的
3. 选风格（深度长文 / 热点速评 / 简明概述）
4. AI 用 Map-Reduce 方式处理：先逐篇提取核心事实，再汇总成「破题 → 分层解析 → 关键事实表 → 盲点延伸 → 升华总结」五段结构

## 悬浮球：它知道你正在干嘛

屏幕右侧的小球不只是个入口。它会检测你当前的活动窗口类型：

- 在 PDF 阅读器里 → 显示 📄 图标，右键菜单多一项「生成阅读笔记」
- 在写作软件里 → 显示 ✍️ 图标，菜单多一项「润色」「引用推荐」
- 热榜有新内容 → 球上冒红点角标
- 上次有未读完的 PDF → 球下方显示「继续阅读 Pxx」横幅

可以拖到屏幕左右边缘 dock，dock 后变成细条贴边，不挡内容。

## 刘看山人格

AI 的对话语气不是标准客服腔，而是知乎官方吉祥物刘看山的口吻：北极小狐狸，偶尔自嘲，会随口冒出"谢邀""利益相关""抖个机灵""先问是不是再问为什么"，像真人聊天一样自然。

## 数据与隐私

- 全部数据（聊天记录、素材库索引、创作快照、历史记录）存在本地 SQLite
- 模型调用走你自己的 API Key，支持 OpenAI / DeepSeek / Kimi / 智谱 / 阶跃 / MiniMax / 百炼 / 自定义
- 可以一键恢复出厂设置清空所有数据

## 快速开始

```bash
npm install
npm run tauri dev    # 开发模式
npm run tauri build  # 打包
```

首次启动 → 双击悬浮球 → 右上角 ⚙️ → 配置你的 API Key。

| 快捷键 | 功能 |
|--------|------|
| `Alt + Q` | 唤出剪贴板快捷菜单 |
| `Alt + S` | 截图 → 选区 → AI 提取 |
| `Alt + E` | 创作快照 |
| `Ctrl + Shift + 1` | 阅读笔记（PDF 场景） |
| `Ctrl + Shift + 2` | 截图提取图表 |
| `Ctrl + Shift + 3` | 截图提取布局 |
| `Esc` | 取消 / 关闭 |

## 其他功能

- **知乎素材库** —— 添加本地文件夹，自动索引 PDF/文档，语义检索。聊天时可自动注入相关片段
- **仪表盘** —— 创作活跃度热力图、事件分布、模型用量统计
- **历史记录** —— 所有快捷操作和截图提取自动留档，输入输出可回看、可复制
- **项目隔离** —— 不同回答/话题可以建不同项目，各自独立对话历史、素材库、统计
- **多语言界面** —— 中文 / English / 日本語
